# Ficha técnica resumida

**Título:** CYBER DOOM — Operação PC Protegido  
**Modalidade:** FPS educativo em primeira pessoa, 2.5D via raycasting  
**Curso:** Técnico em Informática — SENAI  
**Fases:** 3 (Área de Trabalho, Memória do Sistema, Núcleo Infectado)  
**Dificuldades:** Fácil, Médio, Difícil  
**Inimigos:** Vírus, Trojan, Worm, Ransomware  
**Perguntas disponíveis:** 24, com quatro alternativas e explicação  
**Arma:** Disparador de Pulsos Digitais com energia ilimitada e recarga entre pulsos  
**Ranking:** top 10 por dificuldade, apenas LocalStorage  
**Gráficos e áudio:** originais gerados por código, sem arquivos externos  
**Execução:** Navegador moderno + servidor HTTP local, recomendado Live Server no VS Code  
**Preço de serviços remotos:** Nenhum; não há API externa  
**Dependências em tempo de jogo:** Nenhuma  
**Limites:** Sem modo sobrevivência, toque no celular ou ranking em nuvem  
**Testes automatizados executados:** 12 grupos de lógica aprovados com Node.js v22  
**Teste automatizado de interface:** não aprovado/executado até o fim neste ambiente devido ao bloqueio administrativo no Chromium; validar no PC do evento.
